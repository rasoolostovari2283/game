## 🚀 ویژگی‌های شاخص و نوآوری‌های بازی (Key Features)

1. **مکانیک‌های نوآورانه سایبری (Cyber Abilities):**
   * **اتساع زمان ماتریسی (Bullet-Time Slowmo):** با کلید `[SHIFT]` زمان بازی به ۳۵٪ افت می‌کند ولی چابکی فرمان بازیکن با نسبت ۷۲٪ حفظ می‌شود تا لایی‌کشی‌های ناممکن ممکن شود.
   * **هک مسیر و پالس الکترومغناطیسی (Cyber EMP):** با کلید `[E]` پالس نئونی شلیک می‌شود؛ خودروهای ترافیک کنار زده شده و خودروهای پلیس برای ۴.۵ ثانیه فلج می‌شوند.
2. **داشبورد تله‌متری کابین دسکتاپ (Cockpit Telemetry Hub):**
   * **سمت چپ:** تاخومتر آنالوگ (۰ تا ۸۵۰۰ RPM با محدوده قرمز ۷۵۰۰+) و نشانگر دنده فعال گیربکس (GEAR 1 تا 7).
   * **سمت راست:** رادار ناوبری زنده ماهواره‌ای مسیر پیش‌رو، سنسور شتاب جانبی (G-Force Meter) و ردیاب مأموریت فعال.
3. **هوش مصنوعی هوشمند ترافیک با فیزیک ضدتداخل (Anti-Overlap Physics Pass):**
   * حذف کامل باگ فرو رفتن ماشین‌ها در همدیگر با بهره‌گیری از پاس دافعه الاستیک دوطرفه و حفظ فاصله ایمن ۲۴۰ پیکسلی.
   * هوش تعقیب تاکتیکی پلیس (Flanking AI) با محاصره دوجانبه از چپ و راست در سطوح خطر (Heat) بالا.
4. **سنتز زنده صوتی رویه‌ای (Web Audio API Synthesizer):**
   * موسیقی رترو سینث‌ویو ۱۲۴ BPM در گام ر مینور به روش سنتز نوسان‌سازها (کیک ساب‌بیس، اسنیر، های‌هت و بیس غلتان) بدون نیاز به فایل‌های سنگین MP3.
   * شبیه‌ساز دور موتور دندانه‌اره‌ای متغیر بین ۴۵ تا ۲۸۰ هرتز همگام با دنده‌ها و پیچ گاز.
5. **سیستم شرایط جوی و اتمسفر (Dynamic Atmosphere):**
   * شب نئونی (Cyber Night)، هوای بارانی با آسفالت خیس و چاله‌های آب (Rain)، و غروب آفتاب (Sunset).

## 🎮 کلیدهای کنترل نسخه ویندوز دسکتاپ (Keyboard Controls)

| کلید کیبورد | عملکرد |
| :---: | :--- |
| <kbd>W</kbd> یا <kbd>▲</kbd> | گاز و شتاب‌گیری خطی |
| <kbd>S</kbd> یا <kbd>▼</kbd> | ترمز شدید هیدرولیک همراه با دود تایر |
| <kbd>A</kbd> / <kbd>D</kbd> یا <kbd>◄</kbd> / <kbd>►</kbd> | هدایت عرضی خودرو به چپ و راست |
| <kbd>SPACE</kbd> | تزریق نیتروژن مایع (بوست ناگهانی سرعت) |
| <kbd>SHIFT</kbd> | اتساع زمان اسلوموشن ماتریسی |
| <kbd>E</kbd> | شلیک پالس هک مسیر و بمب EMP |
| <kbd>C</kbd> | تغییر زاویه دید دوربین (۲ بعدی، ۳ بعدی و اول‌شخص) |
| <kbd>H</kbd> | بوق زدن (وادار کردن ترافیک جلویی به تغییر لاین) |
| <kbd>P</kbd> یا <kbd>ESC</kbd> | توقف موقت بازی (Pause) |
| <kbd>M</kbd> | قطع و وصل سریع صدا و موسیقی |

## 💻 نحوه اجرای بازی (How to Run)

### روش اول: اجرای مستقیم در مرورگر (بدون نیاز به نصب هیچ پیش‌نیازی)
1. مخزن را دانلود یا کلون کنید.
2. روی فایل `index.html` دو بار کلیک کنید تا بازی در مرورگر مدرن (Chrome, Edge, Brave, Firefox) با نرخ ۶۰ فریم اجرا شود.
3. یا فایل `Play-Game.bat` را اجرا نمایید.

### روش دوم: بیلد دسکتاپ با Electron
```bash
npm install
npm start
```
